# Підготовка до ЄДКІ · криптографія

Статичний сайт для підготовки до ЄДКІ зі спеціальності «Кібербезпека та захист інформації» за темами курсу:
модулярна арифметика, теорія чисел, симетричні та асиметричні криптосистеми (розділ 6 програми ЄДКІ).
Оформлення повторює beamer-тему `Altarguelles` із цього репозиторію.

## Як відкрити

- Локально: відкрийте `edki/index.html` у браузері (потрібен інтернет для шрифтів і KaTeX).
- GitHub Pages: Settings → Pages → Deploy from a branch → гілка `main`, тека `/ (root)`;
  сайт буде доступний за адресою `https://<user>.github.io/<repo>/edki/`.

## Структура

| Файл | Що в ньому |
|---|---|
| `index.html`, `css/style.css`, `js/app.js` | сторінка, стиль, логіка (без збирання й залежностей) |
| `data/test-2027-1.js`, `data/test-2027-2.js` | тренувальні варіанти 2027, по 30 завдань |
| `data/past.js` | збірка минулих років |
| `data/memes.js`, `memes/` | меми: які картинки, з якими підписами і де показувати |

## Як додати завдання

Допишіть об'єкт у масив `questions` (варіант) або `items` (збірка):

```js
{
  t: "6.1.2",                       // пункт програми ЄДКІ
  q: T`Обчисліть $\varphi(360)$.`,   // умова; формули LaTeX у $...$
  o: [T`$72$`, T`$96$`, T`$120$`, T`$144$`],
  a: 1,                             // індекс правильної відповіді, з нуля
  s: T`$360 = 2^3\cdot 3^2\cdot 5$ ...` // розв'язання
}
```

Без полів `o` та `a` завдання показується як відкрите, з кнопкою «Показати відповідь».
Маркер `{{ABC}}` в умові вставляє таблицю українського алфавіту.
Новий варіант — це новий файл у `data/` за зразком наявних плюс рядок `<script>` в `index.html`.

## Вежа на головній

Поверхи вежі задано масивом `FLOORS` у `js/app.js` (назва + пункти програми). Поверх вважається пройденим,
коли правильно розв'язано 80 % його завдань; вершина — 80 % у тренувальному тесті. Прогрес зберігається
в браузері студента (localStorage).

## Меми

Усе керується файлом `data/memes.js`: покладіть картинку в `memes/` (або вкажіть посилання `https://...`),
допишіть запис із підписом і місцем показу. `enabled: false` вимикає меми повністю.

## Про джерела

Тренувальні варіанти 2027 — авторські завдання за програмою (наказ МОН № 980 від 04.11.2022).
У розділі «Минулі роки» — 11 завдань із комплекту ЄДКІ 2023 року, що стосуються тем курсу (офіційних ключів
у комплекті немає, відповіді й розв'язання визначено викладачем), і два завдання за зразками НМЦ ВФПО в переказі.

Ключі: варіант 1 — `BCACBDABCDABCACDBCBBDADCCABCAD`, варіант 2 — `DABDBDCDCBCAACBBCDBCCBCADBCADB`.
